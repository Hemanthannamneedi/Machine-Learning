# Day 57 Assignment – CNN on MNIST Dataset

## Objective
Build and train a Convolutional Neural Network (CNN) to recognize handwritten digits using the MNIST dataset.

## Dataset
- Dataset: MNIST
- Training images: 60,000
- Testing images: 10,000
- Image dimensions: 28 × 28 pixels
- Classes: Digits 0–9

## CNN Architecture
1. Input Layer – accepts 28 × 28 grayscale images.
2. Conv2D – extracts visual features using 32 filters.
3. MaxPooling2D – reduces feature-map dimensions.
4. Conv2D – extracts more complex features using 64 filters.
5. MaxPooling2D – further reduces dimensions.
6. Flatten – converts feature maps into a one-dimensional vector.
7. Dense – learns patterns for classification.
8. Dropout – helps reduce overfitting.
9. Output Dense – predicts one of 10 digit classes using Softmax.

## Training Configuration
- Optimizer: Adam
- Loss Function: Sparse Categorical Crossentropy
- Epochs: 5
- Batch Size: 64
- Evaluation Metric: Accuracy
