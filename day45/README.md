# Day 45 – Exploratory Data Analysis (EDA)

## Project Overview
This project performs Exploratory Data Analysis on a student performance dataset using Python, Pandas, Matplotlib, and Seaborn.

## Objectives
- Load and explore a CSV dataset.
- Identify and handle missing values and duplicate rows.
- Calculate descriptive statistics.
- Visualize data distributions, relationships, and course comparisons.
- Generate five data-backed insights.

## Tools and Libraries
- Python
- Pandas
- Matplotlib
- Seaborn

## Project Structure
- `students.csv` – Student dataset
- `eda_analysis.py` – Complete EDA workflow
- `plots/` – Generated visualization images

## EDA Workflow
1. Load the dataset and inspect its shape, data types, and statistics.
2. Check missing values and duplicates.
3. Standardize text and handle missing values.
4. Generate histograms, scatter plots, and box plots, along with comparison charts.
5. Print five summary insights.

## Run the Project
Install dependencies:

```bash
python -m pip install pandas matplotlib seaborn
```

Run the script:

```bash
python eda_analysis.py
```

## Note
The script introduces simulated missing values and a duplicate row to demonstrate data cleaning. The insights are based on this small educational dataset and should not be generalized to a larger student population.
