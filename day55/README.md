# Advanced Customer Churn Prediction

## Project Overview

A complete Machine Learning project that predicts customer churn using feature engineering, preprocessing pipelines, class imbalance handling and hyperparameter optimization.

## Technologies

- Python
- Pandas and NumPy
- Scikit-Learn
- Imbalanced-Learn
- XGBoost
- Matplotlib and Seaborn
- Joblib

## Machine Learning Techniques

- Feature Engineering
- Feature Scaling
- Missing Value Imputation
- One-Hot Encoding
- SMOTE
- Machine Learning Pipelines
- GridSearchCV
- Cross-Validation
- Model Evaluation

## Algorithms

- Logistic Regression
- Decision Tree
- Random Forest
- KNN
- SVM
- Gradient Boosting
- XGBoost

## Installation

```bash
pip install -r requirements.txt
```

## Run the Project

```bash
python main.py
```

## Generated Outputs

- Model leaderboard
- Hyperparameter tuning results
- Evaluation report
- Confusion matrix
- Feature importance chart
- Saved best model

## Model Storage

The selected model is saved at:

`models/best_churn_model.joblib`

## Evaluation

Models are compared using Accuracy, Precision, Recall, F1-score and training time.

## Disclaimer

This is an educational project using a small sample churn dataset. Its results are not validated for real-world business deployment.
