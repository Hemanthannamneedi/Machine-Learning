# Day 54 – Hyperparameter Tuning, Gradient Boosting & XGBoost

## Overview

This project explores ensemble learning algorithms and hyperparameter optimization using a customer churn dataset.

## Concepts Covered

- Gradient Boosting
- XGBoost
- Random Forest
- Bagging vs Boosting
- GridSearchCV
- Cross-validation
- Hyperparameter optimization
- Model evaluation

## Algorithms

- Logistic Regression
- Decision Tree
- Random Forest
- KNN
- SVM
- Gradient Boosting
- XGBoost

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
python day54.py
```

## Generated Results

- `model_leaderboard.csv`
- `tuning_comparison.csv`
- `plots/model_leaderboard.png`

## Note

This project uses a small educational churn dataset. Results may vary depending on the data and train/test split. The best model is selected based on the measured test F1-score.
